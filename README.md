To-do List

Uma aplicação simples de lista de tarefas desenvolvida para praticar e revisar conceitos de HTML, CSS e JavaScript.

Funcionalidades
Adicionar tarefas
Marcar tarefas como concluídas
Desmarcar tarefas concluídas
Excluir tarefas
Adicionar tarefas pressionando Enter
Tecnologias utilizadas
HTML5
CSS3
JavaScript
Material Symbols
Objetivo

Projeto desenvolvido como prática e revisão dos fundamentos de desenvolvimento web, principalmente manipulação do DOM, eventos, funções, classes CSS e criação dinâmica de elementos.

Como executar

Basta abrir o arquivo index.html em um navegador.
